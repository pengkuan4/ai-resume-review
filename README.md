# AI Resume Review

AI Resume Review is an AI-powered resume diagnosis website for computer science students and new graduates.

The MVP focuses on a simple review flow:

1. Upload a PDF resume.
2. Parse resume text.
3. Send the parsed content to an AI diagnosis workflow.
4. Generate a structured review report.

## Technology Stack

- Frontend: Next.js
- Backend: Spring Boot
- Deployment: Docker Compose and Nginx

## Current Scope

This repository is currently in the project initialization stage. The first phase only defines the project structure and planning documents.

The MVP does not include login, payment, or complex job recommendation features.
